## 〇、我理解的真实系统（能讲给外行听）

**这个系统在造什么**：Personal Brain 是在用户自己服务器上运行的"唯一长期数字记忆"。TRAE/Cursor/ChatGPT/手机都只是它的客户端，换客户端账号、换 AI、聊天被压缩，记忆都还在。它的关键行为是：任何输入先原样保存（raw-first），再派生出 Expense/Todo/事件/候选偏好等结构化结果，派生结果必须能追溯回原始输入；任何客户端访问前先查权限（权限先于检索）；任何不确定/冲突/危险操作不偷偷处理，进 Inbox 或要求确认（governance）；系统离线时诚实报"未保存"而不假装成功（honesty）。

**工程化链路**：`工程母提示词.md`（145 节愿景）→ `spec.md`（103 FR + 12 US + 成功标准）→ `tasks.md`（197 项任务，迁移链 0001..0012）→ 每阶段先写失败测试→实现→回归→`docs/acceptance/*.md` 留证据。当前证据链：431 passed 测试、US1..US12 证据文档、ER-12 基准、加密备份集、隔离 PG 迁移、局域网 Compose 部署、Windows 本机实例、TRAE CN 已完成 bridge 验证。

## 一、我的内核自述（不抄条文）

**一句话**：造的是"任何 AI/客户端可换、用户记忆不换"的服务端唯一权威记忆库（个人知识 + 项目连续性 + 有证据的自画像 + 结构化合账）。

**不可让渡公理（工程上最易踩塌的形态）**：
1. **原始先于派生** —— 原始数据必须保留，派生必须可追溯可重建；（最易踩塌：把 AI 摘要当事实存进权威库）
2. **权限先于检索** —— 客户端永远查不到权限外的东西，拒绝还要记审计；（最易踩塌：先搜后滤 / 手工加 SQL）
3. **诚实优先于成功** —— 离线或失败时报"未保存"，绝不假报成功；（最易踩塌：message 文字写成"保存成功"但实际 pending）
4. **高风险必须确认** —— C 类变化 / 删除 / 权限修改，无确认不执行。（最易踩塌：delete 直接 DROP）

**辨析例（证明理解）**：用户说"今天去京都人太多，午饭 4200 日元"。系统不存"京都=不喜欢"（那是 AI 推断冒充事实），而存 raw 原文 + Expense(4200) + Event(京都) + Experience(主观"人太多") + candidate preference（低置信度）。后来用户在另一次聊天里说"其实我很喜欢京都"——旧推断必须标记 superseded/historical，用户明言优先。这条辨析决定了：canonical 层（raw）永远和 derived 层（标签、摘要）分开存。

## 三、分层根因（为什么存在这些偏移）

1. **外部门禁根因**：T186 需要真实 TRAE/Cursor/ChatGPT/Trilium 账号 + 可达的 HTTPS/OAuth 路由。纯局域网明文 HTTP 无法通过手机/远程客户端 —— 这是**环境边界**，mock 不能替代（ER：诚实优先）。Tribium 同理需真实 endpoint。
2. **协议互操作落地根因**：此前 initialize 强制版本头、不协商版本、未知方法返回 -32000、PING 缺失，都是"按内部约定实现而非按官方 MCP 规范"→ 本会话已修复（协商到 2025-11-25、PING、-32601、VALIDATION_FAILED），TRAE CN bridge 已能通过。
3. **规范-代码漂移根因**：ranking_reasons 写在 ER-03 与 ranking.py 的数据类里，但 compiler 消费排序时只用了 freshness 单一键（compiler.py:26），把 reasons 当死代码输出 —— 体检文档 stage-history 已指出"ER-03 规定 ranking_reasons 代码零实现，规范写了没接线"，**未修**。
4. **部署面漂移根因**：Trilium 是本项目首个"外部系统集成层"。代码层做到可移除（import worker + laid-off 健康），部署层 compose 把 trilium 服务当 optional 省略。类比：Khoj 被正确排除为不依赖，但 Trilium 同属"V1 必需、可移除"（FR-100），部署位应至少在 compose 提供 profile。

## 四、外部参照系（该学/不该学）

- **RAG 知识库（如 AnythingLLM）**：该学"结构化优先于向量"的分流；不该学它对每客户端各存知识（本项目=单一权威）。
- **CoALA 认知架构**：该学"记忆—行动—推理"分层；不该学把 Agent 决策塞进 Brain 本体（Brain 只做权威存储）。
- **Local-first 数据系统（如 Gitea/Trilium 的单文件权威）**：该学 raw 保留 + 派生可重建；不该学无权限粒度（本项目必须有 client×scope×tool 授权）。
- **Bratman 意图理论/Generative Agents 记忆流**：该学 A/B/C 分层（明确/候选/确认）；不该学"重复两次就定型"（ER-02 需要 ≥3 证据/14 天/2 上下文）。

**本项目独有约束（外部没有）**：单 owner、双端权威（服务器 canonical + 客户端临时）、行为验收 12 US + GWT、一切派生带 source/confidence 且不覆盖历史、离线诚实 + 幂等对账、风险分级确认门（ER-06）。
