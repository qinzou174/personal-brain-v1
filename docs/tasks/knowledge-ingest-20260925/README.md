1. 凭据 / 密钥 / 密码永不入知识库（源头不写，隔离机制只是兜底）。
2. 幂等键每次新 uuid；同 key 重放是恢复语义，不是新写入。
3. 一决策一记录；结构化字段（decision/constraint）优先于自由笔记。
4. scope 选对：项目=projects、知识=knowledge、画像=self。
